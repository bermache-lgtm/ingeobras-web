# INGEOBRAS PERÚ E.I.R.L. · Landing web

Sitio estático (HTML + CSS + JavaScript, sin dependencias). Abre `index.html` en el navegador para verlo.

## Publicar gratis con GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo `ingeobras-web`).
2. Sube **todo el contenido de esta carpeta** (`index.html` y la carpeta `img/`) a la raíz del repositorio.
3. Ve a **Settings → Pages**, en *Source* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
4. En 1–2 minutos la web queda en `https://TU-USUARIO.github.io/ingeobras-web/`.

Para usar un dominio propio (ej. `ingeobras.pe`), agrégalo en **Settings → Pages → Custom domain**.
